## Hakkımda

**Kırklareli Üniversitesi Yazılım Mühendisliği** öğrencisiyim. Güvenilir backend sistemleri, modern web uygulamaları ve yapay zekâ entegreli yazılım ürünleri geliştirmeye odaklanıyorum.

Teknik deneyim alanlarım arasında **Java, Spring Boot, C#, .NET, Angular, Python ve ilişkisel veritabanları** bulunuyor. Yazılım geliştirme süreçlerinde temiz mimari, nesne yönelimli programlama, güvenlik, sürdürülebilirlik ve sorumlulukların doğru şekilde ayrılması konularına önem veriyorum.

Özellikle backend mühendisliği, kullanıcı deneyimi ve yapay zekânın birlikte çalıştığı ürünler geliştirmekle ilgileniyorum. Güncel çalışmalarım arasında üniversite topluluk platformları, geliştirici verimlilik araçları, API tabanlı uygulamalar ve üretken yapay zekâ entegrasyonları bulunuyor.

Teknik geliştirme çalışmalarının yanı sıra takım koordinasyonu, proje takibi, mühendislik odaklı Ar-Ge, veri işleme, raporlama ve kurumsal bilgi teknolojileri süreçlerinde deneyim kazandım.

```text

Yapay Zekâ Odağı : Üretken Yapay Zekâ • Prompt Mühendisliği • Geliştirici Araçları

Diller            : Türkçe — Ana Dil • İngilizce — B2
```
